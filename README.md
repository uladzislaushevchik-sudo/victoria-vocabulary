## Как включить GitHub Pages (один раз)

1. Открой репозиторий: https://github.com/uladzislaushevchik-sudo/victoria-vocabulary
2. **Settings** → **Pages** (в левом меню)
3. **Source**: выбери **GitHub Actions**
4. Сохрани
5. Перейди во вкладку **Actions** → последний workflow **Deploy to GitHub Pages** → **Re-run all jobs** (или сделай любой push)

После этого ссылка выше заработает.
